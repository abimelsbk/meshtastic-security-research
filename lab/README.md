# Lab Notes

Use this directory for repeatable, authorized lab procedures and evidence.

Before each experiment, record:
- Hardware and node identifiers (prefer pseudonymous labels)
- Firmware and client versions
- Relevant non-secret configuration
- Test objective and expected behavior
- Start/end time and observed result
- Evidence, limitations, and false positives

Do not commit private keys, channel PSKs, personal data, precise location histories, or sensitive message contents. Use `.gitignore` for local captures and secrets.
